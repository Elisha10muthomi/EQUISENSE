# EquiSense – Stock Investment Expert System

## 📌 Overview

**EquiSense** is a knowledge-based expert system designed to assist investors in making informed stock investment decisions. The system applies rule-based reasoning using financial analysis principles to evaluate stock-related data and generate one of three recommendations:

* **Buy**
* **Hold**
* **Sell**

The project bridges the gap between expert financial knowledge and everyday investors by providing transparent, explainable, and consistent decision support.

---

## 🎯 Objectives

The main objectives of EquiSense are to:

* Analyse key financial indicators relevant to stock investments
* Apply rule-based inference for decision-making
* Support investors with expert-like recommendations
* Improve consistency and transparency in investment analysis

---

## 🧠 Features

* Rule-based expert system
* Buy / Hold / Sell recommendations
* Fundamental analysis integration
* Technical indicator evaluation
* Market sentiment consideration
* Explainable decision-making process
* User-friendly interaction

---

## 🏗️ System Architecture

The system consists of:

1. **User Interface**
   Collects stock-related input from the user.

2. **Knowledge Base**
   Stores financial rules and expert knowledge.

3. **Inference Engine**
   Applies logical rules to determine investment recommendations.

4. **Recommendation Module**
   Outputs Buy, Hold, or Sell decisions.

---

## 📊 Financial Indicators Used

EquiSense evaluates several investment indicators including:

* Earnings Per Share (EPS)
* Price-to-Earnings Ratio (P/E Ratio)
* Stock Price Trends
* Market Conditions
* Company Performance Metrics
* Market Sentiment Indicators

## 🚀 How It Works

1. The user inputs stock-related data.
2. The system processes the information using predefined rules.
3. The inference engine evaluates the conditions.
4. A recommendation is generated:

   * Buy
   * Hold
   * Sell
